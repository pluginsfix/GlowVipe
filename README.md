# GlowVipe

Плагин вайпового хранилища для серверов Minecraft (Paper / Purpur / Folia 1.21, Java 21).

## Возможности

- Покупка слотов вайпового хранилища по очереди за PlayerPoints или Vault.
- Безопасное сохранение предметов между вайпами с защитой от дюпов.
- Удобный графический интерфейс (GUI) с защитой от клик-спама и десинхронизации.
- Поддержка PlaceholderAPI (`%glowvipe_slots%`, `%glowvipe_status%`, `%glowvipe_max_slots%`).
- Полная локализация и звуковое сопровождение действий.

## Команды и права

- `/gv open` (или `/gv menu`, `/gv`) — открыть меню хранилища (право: `glowvipe.use`).
- `/gv reload` — перезагрузить конфигурацию и сообщения (право: `glowvipe.admin.reload`).
